# TalentTrack - Mini Applicant Tracking System

A desktop Applicant Tracking System (ATS) built with Java Swing.

## Features
- Add, update and delete candidates
- Hiring stages: Applied, Screening, Interview, Offer, Hired, Rejected
- Move candidates to the next stage with one click
- Search by name, skill or job role, plus a stage filter
- Dashboard with total, in-pipeline, hired and rejected counts
- Stage-wise bar chart and recent applicants list
- Input validation and duplicate email check
- Data saved in a CSV file (candidates.csv)

## Tech Stack
- Java 17
- Java Swing (GUI)
- File I/O (CSV storage)

## How to Run
1. Install JDK 17 or higher
2. Download `ATS.java`
3. Run these commands in the same folder:

   javac ATS.java
   java ATS
